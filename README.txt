TASKFLOW - PAGINA WEB
=======================
Archivos:
- index.html
- css/style.css
- js/script.js
- img/ (para las capturas reales)

Abrir:
1. Descomprime la carpeta.
2. Abre index.html en Chrome, Edge o Firefox.
3. No necesita servidor.

Capturas:
Guarda las capturas reales de Login, Inicio, Tareas, Calendario, Notas, Metas y Usuario en img/.
Luego sustituye los bloques .placeholder por etiquetas <img src="img/nombre.png" ...>.

La información textual se adaptó de Creación de página web(1) y DERCAS (3).

El logotipo oficial está en img/logo-taskmaster.png.
